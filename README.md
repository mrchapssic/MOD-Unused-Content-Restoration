# -MOD-Unused-Content-Restoration
A mod for restoring unused materials and resources from game files that were not included in the final version.
### Main Changes:

 + Dark theme
 + Weapons and armor
 + New merchants added !
 + Secret weapon recreated
 + Staffs restored, now usable to summon undead creatures!
 + Descriptions for most weapons and armor recreated!

### What was restored:

 + 7 crossbows
 + 1 bow
 + 2 grenades
 + 2 staffs
 + 6 axes
 + 9 armor
 + 2 swords

### We've made some secret items to find them you need to use eye of truth !
